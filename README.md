# Learning Lab

这是一个用于学习、实验和协作的项目工作区。每个子目录通常代表一个独立项目；根目录保存跨项目约定与导航信息，项目自己的依赖、说明和运行方式由各自目录负责。

## 开始使用

1. 在根目录下为新项目创建独立子目录。
2. 在项目目录中维护该项目的 `README.md`、依赖清单和必要的 `AGENTS.md`。
3. 开始前先阅读根目录的 [`AGENTS.md`](AGENTS.md)，遵守其中的协作约定。
4. 将可复用的学习笔记和工作区级说明放在 [`docs/`](docs/) 中。

本仓库目前是空工作区骨架；这里不预设语言、框架或项目模板。每个项目可以按学习目标选择技术栈。

## 建议布局

```text
learning-lab/
├── AGENTS.md          # 工作区与 AI agent 协作约定
├── README.md          # 工作区入口和导航
├── .gitignore         # 常见语言、工具和本地文件忽略规则
├── docs/              # 跨项目学习资料和约定
└── projects/          # 可选：集中放置独立项目
```

也可以直接在根目录下建立项目文件夹；若希望入口保持整洁，建议统一放在 `projects/` 下。

## Git 使用

工作区使用 Git 跟踪文件。提交前检查暂存内容，确认没有本地配置、凭据、模型文件、依赖缓存或生成产物。各项目是否使用独立 Git 仓库，按项目需要决定；避免意外嵌套仓库。

## 文档约定

文档默认使用简体中文，命令、API 名称和代码标识符保留原文。新增项目时，README 应至少说明目标、先决条件、启动/使用方法和验证方法。具体项目说明以项目目录内的文档为准。
